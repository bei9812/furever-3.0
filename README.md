# Furever Story Demo

This folder is a self-contained static bundle for GitHub Pages.

## Entry points

- `index.html` - current event-based Story experience (v7)
- `unified-home-demo-v7-event.html` - same v7 page with its descriptive filename
- `unified-home-demo-v6.html` - previous feed version

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings -> Pages**, select **Deploy from a branch**, choose the default branch and `/ (root)`.
4. Open the generated Pages URL. `index.html` is the landing page.

The bundle is static and uses local mock response files. It does not contain database credentials or service-account data. Video and poster assets are included under `pipi-assets/`, so the repository is approximately 74 MB.
